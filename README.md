# 울산대학교 · 행정 AI 구축과 확산

행정 AI의 구축, 운영, 조직 확산과 인재 양성에 관한 19개 질문을 정리한 HTML 발표자료입니다. 표지와 ‘감사합니다’ 페이지를 포함해 총 21페이지로 구성됩니다.

서비스: [GitHub Pages에서 보기](https://daeung79.github.io/Ulsan_AC/)

## 사용 방법

- 데스크톱: 좌우 방향키 또는 화면 아래 버튼으로 이동합니다.
- 모바일: 세로로 이어서 읽거나 ‘한 장씩 보기’로 전환할 수 있습니다.
- 글자 크기: 모바일 아래의 ‘가−’, ‘가+’ 버튼으로 16~24px 범위에서 조절합니다.
- 텍스트 효과: 제목 순차 등장과 핵심 단어 강조 효과를 켜거나 끌 수 있습니다.
- MongoDB 화면: 이미지를 누르면 확대할 수 있습니다.

## 배포

별도의 서버나 빌드 도구 없이 `index.html`을 제공합니다. 이미지는 HTML 파일에 포함되어 있습니다.

GitHub Pages는 `main` 브랜치의 루트 디렉터리(`/`)를 게시합니다. `index.html`을 수정해 `main`에 반영하면 자동으로 다시 배포됩니다.
